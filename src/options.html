注入

这里是只读视图。要新增目标,请点扩展图标,在弹窗里输入网址并按「开始注入」。
    没有已注入的目标。扩展不会自动作用于任何页面。
    为什么必须手动点: 它换掉的是「常驻能力」——不再有一份写好的名单让扩展自动作用于某些站点,作用范围始终等于你此时此刻点过的那些源。 但它并不是检测机制:点击检测不到任何人的意图,也挡不住自动化点击。真正的收敛来自「不持久」和「随时可收回」这两点。

    遮蔽项

    document.hidden / visibilityState / visibilitychange
    hasFocus / blur / focus / activeElement
    会改变站点真实离站行为
    打开后 pagehide / beforeunload / unload 不再投递 —— 页面自己的「确认离开」提示、卸载埋点都不会执行。自检时它会让被测对象行为失真, 所以默认关闭,需要时再开。
    改动遮蔽项或时序策略会改变注册的文件集合,已武装的页面需要刷新才生效(或重新点一次「开始注入」)。

    预算

    每轮最多推进的虚拟时间 (ms)
    每轮最多补投递的回调数
    低于此间隔的高频计时器只补一次 (ms)
    预算是这套方案唯一「既省 CPU 又完全隐身」的取舍点:补投递被截断的部分会变成 客户端时钟相对墙钟的漂移。harness 会把实际漂移量出来。

    自检

    自检页会逐项测量四类信号,并用 Worker 自身的真实时钟 做交叉验证 —— 那是本扩展不覆盖的一路,能诚实地告诉你还剩多少可被抓的量。
